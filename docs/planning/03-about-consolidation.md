# 03 原首页与 About 整合

状态：待开始。前置：02；内容取舍先交用户确认。

先读 [总览](README.md)、[公共约定](COMMON.md)、[00 交接](00-shared-design.md) 及前置任务的实际交接。先核对现场，再说明第一个小步；以下入口仅供调查，不是任意改写的清单。

## 目标与范围

将原首页和原 About 中用户需要的内容整合到新 About。用户明确要求具体保留、删除内容稍后确认。

## 分步推进

1. 解释首页、About 页面与相关组件的调用关系，逐项盘点原模块及数据来源。
2. 提供保留/修改/删除候选清单和简明布局，等待用户确认具体取舍。
3. 按确认清单整合新 About，避免重复模块和虚构用户资料。
4. 给 04 交接原首页哪些内容已搬迁，避免首页替换丢失用户需要的信息。

## 主要入口

src/pages/index.astro、src/pages/about/index.astro、src/components/home/、src/components/about/、src/site.config.ts。

## 执行时才确定

模块、文案、布局、资料缺口与删除清单。不因规划举过例子就自动保留技能、项目或社交模块。

## 验收

取舍清单经用户确认；About 宽窄屏正常、链接有效；原首页内容去向有记录。构建和生产预览通过。

## 边界

04 负责替换首页，本任务先保证新 About；全站中文化和资料清理由 05 统一核对，不重复维护两套用户资料。
