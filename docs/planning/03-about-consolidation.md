## 可复用接口及最终行为

### ProfileList

- `list` 接收数组；每项必填 `name`、`avatar`、`href`，可选 `description`。avatar 是导入的本地图片元数据。
- 保留填写顺序，链接在当前页打开；卡片外观来自原 FriendList，注明 Astro Theme Pure 来源与 Apache-2.0 许可。原 FriendList 和安装包未修改。
- 文字区固定 56px：昵称单行；说明最多两行；有说明时昵称顶部对齐；省略或纯空白说明时昵称垂直居中。
- 图片默认透明；成功添加 data-loaded，失败添加 data-failed，并移除相反标记。初始不显示占位，失败才显示轮廓。保留语义 alt，同时避免可见破图与替代文字超框。
- 失败占位圆底读取 `hsl(var(--primary) / 0.12)`，轮廓读取主题主色。
- 最新要求为前景头像和失败占位都使用 `opacity 0.2s ease`，通过两个并列选择器共享过渡；装饰背景不参与此过渡，成功时透明度 0.15。用户已自行完成此修改；按其要求不再重复核对或测试。

### ProfileLayout 与 top/sidebar

- 参数：必填 `name`、本地图片 `avatar`，可选 `links: { label, href }[]` 与 `headings`，后两者默认空数组。
- 顶部资料填入 ContentLayout 的 top，目录由 headings 生成 TOC 填入 sidebar，正文通过默认插槽传入。现有作者正文没有小标题，因此目录内容为空；不虚构标题。
- 作者名为唯一 h1，浏览器标题同样读取 name；返回按钮链接 `/about`。
- 作者页迁入原首页主题仓库链接，标为“主题源码”，没有代填个人账号；之后编辑 links 即可替换。
- 顶部沿用主题 animate / fade-in-up 载入动画，时长 300ms，元素内联设置延迟 50ms。
- 头像三层：固定 112px 透视容器（800px）→ Z 轴深度/阴影层 → 圆心旋转层。
- 仅 `.profile-stage:hover` 触发深度层 `translateZ(20px)` 和内层 `rotate(-4deg)`，0.25s 过渡；保持悬停则停住，离开复原，不自动循环、不做 Y 轴平移。主规则中的整组 focus-within 触发已由用户移除。
- 阴影与头像同心：静止 `0 0 5px / 0.06`，抬起 `0 0 24px / 0.18`。减少动态效果分支关闭位移与旋转；其中残留的旧焦点禁用选择器不会触发动作，旧“链接获得焦点”注释也尚未清理，不作为功能阻塞项。
